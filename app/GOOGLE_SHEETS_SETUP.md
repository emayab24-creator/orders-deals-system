
# Настройка Google Sheets интеграции

## Обзор

Это приложение теперь поддерживает интеграцию с Google Sheets для автоматического сохранения и синхронизации обработанных данных товаров. Данные сохраняются как в локальном JSON файле (как резерв), так и в Google Таблице.

## Особенности интеграции

- ✅ **Двойное сохранение**: Данные сохраняются локально И в Google Sheets
- ✅ **Fallback система**: Если Google Sheets недоступен, работает с локальными файлами
- ✅ **Автоматическая синхронизация**: При обработке товаров данные автоматически попадают в таблицу
- ✅ **Управление заголовками**: Автоматическое создание правильной структуры таблицы
- ✅ **Поиск и обновление**: Умное обновление существующих записей
- ✅ **Веб-интерфейс настройки**: Простой интерфейс для подключения таблицы

## Быстрый старт

### 1. Создание Google Service Account

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте новый проект или выберите существующий
3. Включите Google Sheets API:
   - Перейдите в "APIs & Services" → "Library"
   - Найдите "Google Sheets API" и включите его
4. Создайте Service Account:
   - Перейдите в "APIs & Services" → "Credentials"
   - Нажмите "Create Credentials" → "Service Account"
   - Заполните данные и создайте аккаунт
5. Создайте ключ:
   - Откройте созданный Service Account
   - Перейдите на вкладку "Keys"
   - Нажмите "Add Key" → "Create New Key" → "JSON"
   - Скачайте JSON файл

### 2. Создание Google Таблицы

1. Создайте новую [Google Таблицу](https://docs.google.com/spreadsheets/)
2. Скопируйте ID таблицы из URL:
   ```
   https://docs.google.com/spreadsheets/d/ВАSH_SHEETS_ID/edit
   ```
3. **Важно**: Предоставьте доступ Service Account к таблице:
   - Откройте таблицу
   - Нажмите "Поделиться" в правом верхнем углу
   - Добавьте email из JSON ключа (поле "client_email")
   - Дайте права "Редактор"

### 3. Настройка приложения

#### Вариант A: Через веб-интерфейс (Рекомендуется)

1. Запустите приложение
2. Войдите как администратор
3. Перейдите на вкладку "Google Sheets"
4. Вставьте URL или ID вашей таблицы
5. Вставьте JSON ключ Service Account
6. Нажмите "Сохранить настройки"
7. Нажмите "Тест подключения"
8. При успехе нажмите "Инициализация" для создания заголовков

#### Вариант B: Через переменные окружения

1. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```

2. Отредактируйте `.env` файл:
   ```env
   GOOGLE_SHEETS_ID=ваш_id_таблицы
   GOOGLE_SERVICE_ACCOUNT_KEY={"type":"service_account","project_id":"ваш_проект",...}
   ```

3. Перезапустите приложение

## Структура данных

Приложение создает в Google Таблице следующие колонки (A-AE):

| Колонка | Название | Описание |
|---------|----------|----------|
| A | № | Порядковый номер |
| B | Запрос | Исходный запрос пользователя |
| C | Наименование | Полное наименование товара |
| D | Бренд | Бренд/производитель |
| E | Артикул | Артикул товара |
| F-L | Количество/Цены | Количество, цены, итого |
| M | ТН ВЭД | Код ТН ВЭД (10 цифр) |
| N | НДС | Ставка НДС |
| O | Пошлина | Ставка пошлины |
| P | Группа | Группа/категория товара |
| Q | Описание | Подробное описание |
| R-U | Техх. хар-ки | Электрические параметры, давление, среда, диаметр |
| V-W | Материал/Фото | Материал изготовления, ссылка на фото |
| X-Z | Компания | Марка, производитель, страна |
| AA-AE | Сертификация | Данные о сертификации и сертификаторах |

## API Endpoints

Для программной работы с Google Sheets доступны следующие endpoints:

### `GET /api/google-sheets/test`
Проверка подключения к Google Sheets

### `POST /api/google-sheets/init`
Инициализация таблицы (создание заголовков)

### `GET /api/google-sheets/data`
Получение всех данных из таблицы

### `POST /api/google-sheets/data`
Добавление нового товара в таблицу
```json
{
  "productData": {
    "Наименование": "Название товара",
    "Бренд": "Бренд",
    ...
  }
}
```

### `DELETE /api/google-sheets/data`
Очистка данных в таблице (кроме заголовков)

## Решение проблем

### Ошибка "GOOGLE_SHEETS_ID environment variable is required"
- Google Sheets не настроен, это нормально
- Приложение будет работать только с локальными файлами
- Настройте интеграцию через веб-интерфейс

### Ошибка "GOOGLE_SERVICE_ACCOUNT_KEY environment variable is required"
- JSON ключ Service Account не найден
- Проверьте настройки в веб-интерфейсе или .env файле

### Ошибка "Failed to connect to Google Sheets"
- Проверьте правильность JSON ключа
- Убедитесь, что Google Sheets API включен в проекте
- Проверьте права доступа Service Account к таблице

### Ошибка "Forbidden" или доступа
- Service Account не имеет доступа к таблице
- Поделитесь таблицей с email из поля "client_email" JSON ключа
- Дайте права "Редактор"

### Данные не сохраняются в Google Sheets
- Проверьте логи приложения
- Данные всегда сохраняются в локальный файл как резерв
- Google Sheets - дополнительная функция, не критичная для работы

## Безопасность

- JSON ключи Service Account содержат секретную информацию
- Не публикуйте их в открытых репозиториях
- Используйте переменные окружения для продакшена
- Service Account имеет минимальные права только на Google Sheets API

## Преимущества интеграции

1. **Совместная работа**: Несколько пользователей могут работать с данными
2. **Резервное копирование**: Данные хранятся в облаке Google
3. **Экспорт**: Легко экспортировать в Excel/CSV из Google Sheets
4. **Автоматизация**: Можно подключить скрипты Google Apps Script
5. **Доступность**: Доступ к данным из любого места
6. **История**: Google Sheets ведет историю изменений

## Лимиты Google Sheets API

- 100 запросов в секунду на пользователя
- 1000 запросов в секунду на проект
- Приложение автоматически управляет частотой запросов
